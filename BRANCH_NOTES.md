During the development process, an unintended Git pull/merge operation caused changes from the shared 'main' branch to be incorporated into my original individual development branch.
Since the shared branch contained contributions from all four group members, files belonging to other modules became part of my working branch.
To resolve subsequent integration issues and continue developing Module 4 without disrupting the shared project, I created additional integration branches.
These branches were used to manage merge conflicts, transfer my individual changes, and integrate Module 4 into the group project.
Therefore, the presence of files from other modules in my branches should not be interpreted as work individually implemented by me.
